# 架构说明

## 输入与单位

入口为 `run.py` 或安装后的 `uav-cooperation` 命令。`MissionRequest.from_dict` 检查任务 JSON 的字段、数值、三维边界、障碍几何和机群配置。位置单位为米，时间为秒，速度为米/秒，坐标系为 `local_xyz_m`。

完整合同见 [输入输出说明](../完整代码/docs/输入输出说明.md)。模型、经纬度和其他坐标系须在输入前转换。

## 离线规划

`application/pipeline.py` 组织以下阶段：

1. 建立任务与各机起降节点，计算欧氏距离，并按选定策略挑选需要预计算 A* 的点对。
2. `VoxelGrid` 处理几何障碍和安全膨胀，`EndpointAStar` 连接原始端点并搜索体素路径；`PathStore` 复用已有航段。
3. OR-Tools Routing 计算任务归属和访问顺序，约束各机可用任务时间；默认使用并行最便宜插入和贪心下降，也可使用 GLS。
4. 为分配后实际使用、尚未搜索的航段补算 A*，组装完整路径，复核任务恰好访问一次、路线碰撞和实际续航。
5. 按速度和任务驻留时间构造时间轨迹，检测机间冲突，通过起飞延迟搜索错峰方案。
6. 输出包含输入指纹、算法元数据、约束检查、路线与阶段耗时的规划结果。

求解器目标使用毫秒向上取整后的 `10000 × 最大单机任务时间 + 总任务时间`。它使用分配矩阵估算，须与最终实际 A* 航程及错峰后的完成时间区分。超出续航时返回不可行，不会自动开始新一轮重分配。

## 在线执行仿真

`simulation/api.py` 校验输入与规划匹配，`simulation/online.py` 随离散时间步推进各机状态。`realtime_avoidance/` 接收局部障碍和邻机状态，产生局部避障/等待等决策。输出包括轨迹行、任务访问、碰撞、机间冲突、飞行时长和可行性。

在线障碍可为静止或匀速运动球体。当前保存的两个桥梁示例没有额外运动球体，相关结果仅对应其已配置环境。

## 可视化与导出

`visualization/viewer.py` 使用 Matplotlib 绘制障碍、任务点和规划航线，提供时间滑块与播放。`launch.py` 使用 WebAgg 在 `127.0.0.1` 提供浏览器回放。该回放展示规划时间轨迹；在线仿真轨迹另存于 `online_simulation.json`。

`io/exports.py` 导出规范化输入、规划、任务分配、航点和 A* 航段耗时。可通过 CLI 显式请求 PNG 快照。

## 交付方式

Git 保存源代码、任务输入、来源记录、预置结果、图片和 Markdown 文档。Release 提供包含 Windows x64 Python 及依赖的便携包。Word 文档仅保留在本地，不进入源码仓库或 Release。便携包和源码版使用相同的项目代码；源代码安装与便携运行的入口保持一致。
