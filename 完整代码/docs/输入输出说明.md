# 输入输出说明

## 输入原则

入口接收一个任务 JSON。所有位置统一为本地直角坐标 `local_xyz_m`，单位为米；时间为秒，速度为米/秒。更换场景只需替换任务与环境数据，无需修改桥梁代码。经纬度、模型坐标转换和复杂模型转障碍物须由上层先完成。

必需顶层字段：`drones`、`tasks`、`environment`。可选字段：`schema_version`（目前为 `1.0`）、`name`、`coordinate_frame`、`drone_count`、`planning`、`safety`、`online`。若填写 `drone_count`，必须与无人机列表长度一致。未识别的字段会被拒绝，以避免参数拼写错误被静默忽略。

## 无人机 drones

每架无人机分别填写：

| 字段 | 必需 | 含义/默认值 |
|---|---|---|
| `id` | 是 | 唯一非空标识 |
| `start_m` | 是 | 起飞位置 `[x,y,z]` |
| `end_m` | 否 | 降落位置，默认返回该机起飞点 |
| `available_flight_seconds` | 是 | 根据当前剩余电量估计的可用空中时间，必须大于0 |
| `reserve_seconds` | 否 | 预留空中时间，默认0 |
| `cruise_speed_mps` | 是 | 起降点与任务点之间的巡航速度 |
| `inspection_speed_mps` | 否 | 任务点之间的速度，默认与巡航速度一致 |

有效续航 = `available_flight_seconds - reserve_seconds`，必须大于0。每架无人机可以不同。任务时间包含沿路径飞行时间和任务点驻留，地面错峰等待不计入空中时间。该模型不包含功率、风速、载荷、电压和电量百分比换算。

## 任务 tasks

| 字段 | 必需 | 含义/默认值 |
|---|---|---|
| `id` | 是 | 唯一非空任务标识 |
| `position_m` | 是 | 要访问的位置 `[x,y,z]` |
| `dwell_seconds` | 否 | 任务驻留时间，默认2；允许为0 |

所有任务必须恰好分配一次。当前输入要求任务坐标互不重复；同位置任务应先合并为一个任务并累加驻留时间。任务与起降点可以同坐标，二者仍保留各自身份。当前没有任务优先级、时间窗、载荷需求或无人机能力匹配字段。

## 环境 environment

`map_min_m` 和 `map_max_m` 定义三维规划边界；各轴上界必须大于下界。边长必须为网格分辨率的整数倍，网格节点总数不得超过2000万。无人机起降点和任务点必须处于边界内，且不能位于按机体半径和障碍余量膨胀后的障碍物内。

`obstacles` 为障碍物列表，默认空列表，目前支持长方体、Z向圆柱和闭合三角网格：

```json
{"type":"cuboid","center_m":[30,20,7],"size_m":[6,18,14],"label":"wall"}
```

```json
{"type":"cylinder_z","center_m":[20,20,5],"radius_m":2,"height_m":10,"label":"column"}
```

圆柱轴线沿Z轴。`label` 可省略；尺寸、半径、高度必须大于0。

闭合三角网格使用`{"type":"triangle_mesh","vertices_m":[[x,y,z],...],"faces":[[i,j,k],...],"label":"bridge"}`，顶点为米制坐标，面片索引从0开始；不得超过50000个三角面。每条边必须恰好连接两个面且绕序一致；拒绝开口、退化面和零体积构件。多个闭合构件按实心并集合并，重叠处不会变为自由空间。此语义不用于表达以分离内壳定义的空心材料，输入应先按实体构件整理。

`environment.mesh.read_stl`可读取二进制/ASCII STL并转换为上述便携式内嵌输入。目前没有OBJ、点云或GIS直接输入适配。STL不自带可靠单位与坐标系，需由场景准备步骤明确换算并记录变换。

网格障碍采用按无人机半径和安全余量的球形距离判断；体素化额外预留半个网格体素对角线，避免薄构件落在节点之间被遗漏。端点接入、路径简化与最终复核直接使用原始三角形的线段相交和扫掠球距离检查。原长方体/圆柱仍使用原有采样线段检查。两种判定均属于数值规划验证。

## 规划 planning

| 字段 | 默认 | 含义 |
|---|---|---|
| `distance_strategy` | `hybrid` | `euclidean` 全部直线代价；`hybrid` 混合代价；`astar` 全部点对A*代价 |
| `astar_threshold_m` | 600 | 混合策略中直线距离≤阈值的点对先运行A*，包括起降点连接 |
| `grid_resolution_m` | 10 | 三维网格间距 |
| `heuristic_weight` | 1.2 | Weighted A*启发权重，至少为1 |
| `max_astar_expansions` | 2000000 | 单条路径最大扩展节点数 |
| `allocation_strategy` | `pci_greedy` | 并行最便宜插入＋贪心下降；`pci_gls`切换为原并行最便宜插入＋GLS |
| `solver_time_limit_seconds` | 30 | OR-Tools搜索时间上限；贪心可能提前结束，不含矩阵准备和最终路径验证 |
| `solution_limit` | 10000 | OR-Tools解数量上限 |
| `seed` | 20260910 | 求解器种子参数 |
| `require_all_drones_used` | false | 开启后检查每架无人机是否分到至少一个任务，未满足则拒绝结果 |

三种策略的最终实际航段都由 A* 生成。混合策略的长距离分配代价是近似值，可能低估绕障距离，因此组装实际路线后再次检查续航；若超限会返回不可行，不会自动重新分配。求解器在限时内搜索，不承诺全局最优或每次运行完全相同。

起终点允许不位于网格节点。适配器保留原坐标，通过可碰撞检查的连接段接入邻近网格；复杂狭窄环境中可能无法找到连接节点，需要调整网格分辨率或输入位置。路径段使用原有采样碰撞检测，不构成连续空间安全证明。

## 安全 safety

| 字段 | 默认 | 含义 |
|---|---|---|
| `uav_radius_m` | 0.5 | 通用机体碰撞半径 |
| `obstacle_margin_m` | 0 | 静态障碍额外余量 |
| `minimum_separation_m` | 20 | 无人机中心之间的最小间距，至少为两倍机体半径 |
| `collision_sample_step_m` | 5 | 路径段碰撞采样间距 |
| `delay_step_seconds` | 1 | 错峰起飞搜索时间步长 |
| `maximum_departure_delay_seconds` | 600 | 单机最大起飞延迟 |

半径、余量与间距目前为机群通用参数。起飞延迟的搜索步数上限为10000。6架以内活动无人机枚举优先顺序，超过6架使用4种启发顺序；没有可行错峰方案时拒绝结果。

## 在线参数 online

可选参数：`planning_update_hz`（默认2）、`prediction_horizon_s`（默认10）、`sensor_range_m`（默认100）、`maximum_simulation_overtime_s`（默认600），均须大于0。额外在线障碍列表 `obstacles` 默认空列表，支持静止/匀速运动球体：

```json
{
  "id":"O1","kind":"moving","radius_m":2,
  "center_m":[18,10,5],"velocity_mps":[0,-1,0],
  "active_start_seconds":0,"active_end_seconds":30
}
```

`kind` 为 `static` 或 `moving`。省略速度为零，静止障碍不可设置非零速度；起始时刻默认0，结束时刻省略或为null表示持续存在。球体中心位置以启用时刻为基准。无人机邻居状态由单次在线避障接口提供，不属于离线任务列表字段。

## 输出

| 文件 | 内容 |
|---|---|
| `mission.json` | 本次实际使用的输入，包含命令行覆盖参数 |
| `plan.json` | 完整规划、任务归属顺序、真实路线、续航、安全与各阶段耗时 |
| `assignments.csv` | 每架无人机按访问顺序排列的任务标识；时间、距离及起飞延迟见plan.json |
| `waypoints.csv` | 每架无人机按顺序拼接的三维航点 |
| `edge_timing.csv` | 每条A*航段的阶段、端点、耗时、直线长度、真实路径长度与扩展节点数 |
| `online_simulation.json` | 在线仿真时的轨迹、避障决策、覆盖和碰撞统计 |
| `preview.png` | 显式指定快照时生成的三维路线预览 |
| `error.json` | 输入或规划被拒绝时的原因 |

`plan.json` 的 `feasible` 只有在任务覆盖、采样碰撞检查、实际续航检查和错峰后机间冲突检查均通过时才为true。`reassignment_required` 标识真实绕障路线是否超出续航。无可行分配或无法错峰时入口抛出异常，命令行返回2。

`actual_makespan_before_scheduling_s` 为最大单机任务时间；`makespan_after_scheduling_s` 包含地面错峰起飞延迟；在线仿真时间还包括实际避障与空中等待。规划计算秒数和任务执行秒数须分别使用，不应混淆。

新规划的`allocation`记录实际分配策略、OR-Tools初始解和局部搜索枚举、求解器状态、估计矩阵目标值、纯搜索秒数`search_time_s`及`optimality_proven=false`。其中目标值采用逐弧毫秒向上取整后的`10000*最大单机任务时间+总任务时间`，不同于最终实际A*与调度时间。`timing_s.or_tools_s`还包含分配建模与结果提取；`timing_s.wall_s_including_scheduling_and_progress`记录含A*和调度的完整规划函数墙钟时间，不含Python启动、导入和结果文件写入。历史规划可能没有`allocation`字段，不应按当前默认值反推其求解算法。
